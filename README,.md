# Personal Mini-Toolkit

## Project Description

The Personal Mini-Toolkit is a Python menu-driven program containing three useful tools. The tools are a simple calculator, a shopping list manager, and an even-or-odd number checker. The program uses variables, input/output, conditionals, loops, lists, and f-strings.

## Tools

### 1. Simple Calculator

The calculator performs addition, subtraction, multiplication, and division.

### 2. Shopping List

The shopping list allows the user to add items, view items, and remove items while the program is running.

### 3. Even or Odd Checker

The number checker determines whether a whole number is even or odd.

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the following command:

```text
python toolkit.py
```

4. Choose a tool from the menu.
5. Follow the instructions shown by the program.
6. Choose option 4 to quit.

## Reflection

The hardest part of this project was connecting all three tools to one main menu while making sure the menu returned after each tool finished. The part that required the most testing was the shopping list because I needed to make sure items could be added, displayed, and removed correctly. I also had to make sure removing an item that was not in the list did not cause the program to crash. Testing invalid menu choices helped me understand how important `if`, `elif`, and `else` are in a menu-driven program. I enjoyed building the calculator because it helped me practice using user input and conditional statements. If I had one more week, I would add a number-guessing game and a countdown timer. I would also improve the toolkit by saving the shopping list so that it could be used again after the program closes.
